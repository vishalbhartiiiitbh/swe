**Institution:** IIIT Bhagalpur

**Project Code:** P04 — Social Networking Application  

## How to Run Offline on Any PC
1. Extract this ZIP folder anywhere on your computer.
2. Double-click **`index.html`** to open it directly in Google Chrome, Microsoft Edge, Firefox, or Brave.
3. **Zero internet connection, servers, or installations required.** All accounts, profiles, friend requests, posts, and messages persist automatically in the browser's local database (`localStorage`).

## Implemented Functional Requirements
- **Account Registration:** Name, unique email validation, password length validation, and minimum age verification (`>= 13` years).
- **Authentication:** Secure login/logout session handling.
- **View & Edit Full Profile:** Edit Date of Birth, Address, Phone Number, Education, Profile Photo (local image upload, URL, or built-in avatar presets), Professional Info, and Hobbies.
- **Friend Discovery & Requests:** Search users, send friend requests, accept/decline incoming requests, and view friends' basic profiles (with privacy controls on phone numbers for non-friends).
- **Direct Messaging:** 1-on-1 real-time messaging strictly gated to accepted friends.
- **Social Feed & SE Specs Tab:** Publish tagged posts, like posts, and inspect the Software Engineering specifications (Actors, Use Cases, Data Model, and Enforced Business Rules) directly inside the app via the **SE Specs** tab.
